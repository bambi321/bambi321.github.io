# Polynomial · operations site

The root GitHub Pages site for **Polynomial** ([@_poly_nomial_](https://www.instagram.com/_poly_nomial_/)): the best moments from the greatest science and maths channels, as short clips.

This repo holds only the small files that need to live at the top of `bambi321.github.io`. The real website lives in the main repo.

| What | Where |
|---|---|
| Website (home, privacy, terms) | https://bambi321.github.io/poly_nomial_clips/ |
| Website source | [`poly_nomial_clips/site/`](https://github.com/bambi321/poly_nomial_clips/tree/main/site) |
| This repo, served at | https://bambi321.github.io/ |

## Files

| File | Why it's here |
|---|---|
| `index.html` | Sends anyone who opens `bambi321.github.io` on to the Polynomial site |
| `google*.html` | Proves to Google Search Console that we own `bambi321.github.io`. Needed for the Google Cloud app's branding check (YouTube posting). **Don't delete or rename it**, or the verification lapses |

## Publishing

GitHub Pages serves this repo straight from the `main` branch (**Settings → Pages → Deploy from a branch → main / root**). Push and it's live within a minute or two.

For it to be served at the root address (`bambi321.github.io`, not `bambi321.github.io/<repo-name>/`), the repo must be named exactly **`bambi321.github.io`**.
